# 开发日志与实测归档 (`devlog/`)

本目录存放 `dsh-qqbot-bridge` 演进过程中的方向基准、设计方案、适配规划、真机探针纪要与历史归档文档（面向维护者与开发者；面向用户的开源专题文档请参阅 [docs/README.md](../docs/README.md)）。

---

## 测试标准环境声明

> [!IMPORTANT]
> **本目录中全部真机探针与接口实测结论，均基于「拥有该 QQ Bot 管理员权限的机器人创建者个人 QQ 账号」在 QQ 开放平台官方 Bot API v2 单聊（C2C）环境下测试得出。**
>
> **不保证其他形态的账号**（例如：非创建者 / 非管理员的普通体验用户账号、沙箱或特殊白名单测试账号、企业主体或不同权限等级的机器人账号、以及群聊 / 频道等非 C2C 场景）**具有一致的接口配额、消息下发、主动推送或交互回调行为。**

在阅读或复用本目录下的协议边界结论（如被动回复窗口、`msg_seq` 去重、流式字节上限、富媒体分片上传、`INTERACTION_CREATE` 回调等）时，请务必结合自身账号主体与权限形态重新核验；发现差异时请以实际探针响应为准。
